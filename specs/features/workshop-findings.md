# Feature: Workshop Findings Dashboard

## Summary
McKinsey-grade assessment findings with multiple deliverable assets.

## Deliverables
1. **Assessment Report** — 8-10 page full domain analysis
2. **Transformation Roadmap** — Phased tracks with milestones
3. **Architecture Deep Dive** — Technical architecture review
4. **Executive Briefing** — 2-page board-ready summary
5. **Gap Analysis Document** — Per-dimension gap tables

## Dashboard Sections
- Executive hero banner (SVG dial, 4 KPIs, gap severity)
- Maturity distribution + strengths/weaknesses
- Readiness Spine + Gap Heatmap
- Deep level analysis (expandable dimension drill-down)
- Workstream impact analysis
- AI current-state narrative
- Strategic Recommendations Engine (4 categories, AI generation)
- Investment & phasing roadmap
- Readiness checklist

## Done Contract
- [ ] All 5 asset types generate and open as HTML
- [ ] AI narrative generates without error
- [ ] AI recommendations return 12+ items with metadata
- [ ] Each recommendation has: text, category, impact, effort, KPIs
- [ ] Readiness checklist shows 5 gates
- [ ] HTML export includes full styling and print support
