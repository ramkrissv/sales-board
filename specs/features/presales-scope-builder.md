# Feature: Presales Scope Builder

## Summary
Structured scope items in the Solutioning tab, matching workshop scope format.

## Capabilities
- 8 default workstreams (Discovery, Architecture, Dev, QA, DevOps, Data/AI, Training, PM)
- 5 execution models per item (Pod Squad, Managed Capacity, Outcome-Based, AI-Powered, Hybrid)
- Phase (P1/P2/P3) and effort points (1-10) per item
- AI Generate Scope from deal context + requirements + architecture notes
- Inline add/edit/delete within workstream groups
- Push to Studio (converts scope → proposal sections)
- Effort Estimator integration (scope summary in estimator card)
- Enhanced PDF/DOCX/Markdown exports with scope tables

## Done Contract
- [ ] Scope items display grouped by workstream
- [ ] AI generates 6-10 items from deal context
- [ ] Push to Studio creates proposal sections with execution models
- [ ] Effort Estimator shows scope summary
- [ ] All 3 export formats include scope table
