Security & Guardrails

Enterprise-Grade Security.
Startup Agility.

AI Safety

Human-in-the-Loop

  • Every AI output is a proposed draft
  • Accept / Edit / Discard on all outputs
  • AIInteraction log records every call
  • Consistency check flags contradictions
  • No auto-commit of AI content
Infrastructure

Server-Side Only

  • API keys never reach client
  • Zod validation at every boundary
  • Server Actions for all mutations
  • Ownership checks on every query
  • Typed end-to-end: TS strict, no any
Access

Authentication & RBAC

  • Microsoft SSO (Azure AD)
  • 2FA (TOTP authenticator)
  • 4-tier RBAC: Owner → Viewer
  • MCP tools with granular permissions
  • Multi-tenant data isolation
