ENGINE CONFIGURATION Agent Read-Only

  • Isolated sub-agent personas with constraints
  • Planner: specs → execution plans
  • Generator: independent code-writing with guardrails
  • Evaluator: strict grading rubric (7 criteria)
  • Slash commands mapped to .md files
  • Reusable skills & technical pattern snippets

SPEC ENGINEERING Immutable

  • ARCHITECTURE.md — core technical boundaries
  • Feature specs with acceptance criteria
  • Done contracts: JSON schemas defining "success"
  • Agents read but never modify specs

FLOW ENGINEERING Agent Read-Write

  • Reusable workflow YAML (deploy, build, test)
  • tasks.json — single-source-of-truth state machine
  • Planner writes workflows, Generator reads them

HARNESS ENGINEERING Validation Loop

  • Agent evals — regression benchmarks for prompt drift
  • Quality gates per AI assist (accept rate, output length)
  • Integration tests for critical flows

OBSERVABILITY LAYER Append-Only

  • AI interaction traces (input, output, status, model, cost)
  • Latency metrics per assist type
  • Accept/reject rates for prompt tuning signals

ECONOMICS & SAFETY System Caps

  • Token budgets: daily/monthly dollar caps
  • Model tier routing (haiku → sonnet → opus)
  • Rate limits per endpoint category

SECURE ACCESS LAYER Sandbox

  • File write allowlist/denylist per agent
  • Git operation guardrails (no force push)
  • Network allowlist (API endpoints only)
  • High-risk changes queued for human approval

ROOT CONFIG FILES

  • .githooks/ — pre-commit (secrets scan, TypeScript check) + pre-push (build verify)
  • .mcp.json — Model Context Protocol tool schemas
  • CLAUDE.md — global routing + bootstrap rules
  • CLAUDE.local.md — user-specific overrides (gitignored)
